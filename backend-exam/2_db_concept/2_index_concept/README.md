## Response Section
ข้อดีของ Database indexing คือ การที่ช่วยในการค้นหาข้อมูลได้เร็วขึ้นเนื่องจากข้อมูลแบบ index ข้อมูลแต่ละตัวจะมี index เป็นของตัวเอง

การ  Select  เร็วขึ้นเพราะไม่ต้อง เรียกจาก 1-100 ให้ไปหาที่ index ของข็อมูลนั้นเลย ทำให้เร็วขึ้น
การ Where   เร็วขึ้นเพราะหา Row ตาม index 
การ Join ช่วยให้การค้นหาข้อมูลระหว่าง Table มีประสิทธิภาพขึ้น
การ Order by Index บางแบบสามารถช่วยในการเรียงลำดับได้
การ UNIQUE สามารถใช้ Unique Index เพื่อป้องกันข้อมูลซ้ำได้
ข้อเสีย
ใช้พื้นในการเก็บเพื่มเพราะต้องเก็บ Index ด้วย
Insert ช้าลงเพราะต้องเพื่มข้อมูล ที่ table และ ที่ indexด้วย
Updata ช้าลงเพราะต้องแก้ข้อมูล ที่ table และ ที่ indexด้วย
Delete ช้าลงเพราะต้องลบข้อมูล ที่ table และ ที่ indexด้วย
และถ้ามี index เยอะจะทำให้ระบบช้า
