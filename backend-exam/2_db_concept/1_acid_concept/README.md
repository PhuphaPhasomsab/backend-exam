## Response Section
A คือ Atomicity คือการที่การทำรายการได้ก็ตามรายการนั้นต้องส่งข้อมูล/รับข้อมูลทั้งหมดโดยที่ไม่มีอะไรขาดหาย ถ้าขาดหายให้ไม่ทำอะไรเลข 
เช่นสมมติ
ID Name Balance
1  nueng 100
2  john  100
john ทำรายการโอนเงินให้ nueng  50 
ข้อมูลควรจะเป็น
ID Name Balance
1  nueng 150
2  john  50
แต่ถ้าโอนแล้วข้อมูล เงิน john หายแต่ nueng เงินเท่าเดิม
ID Name Balance
1  nueng 100 >> เงินไม่เพื่ม
2  john  50  >> เงินหาย
แบบนี้ไม่ควรเกิด
แต่ถ้าหายให้ยกเลิกแล้วกลับไปค่าดังเดิม
เช่น โอนแล้วข้อมูล เงิน john หายแต่ nueng เงินเท่าเดิม ให้ดึงข้อมูลกลับเป็นเหบือนเดิม
ID Name Balance
1  nueng 100
2  john  100

C คือ Consistency  คือ ข้อมูลต้องถูกต้องตามกฎของ database
เช่นการ ที่ 
ID Name Balance
1  nueng 0
2  john  100
แต่ nueng อยากโอน 20 ไปให้ john แต่ nueng ไม่มีสักบาทก็ไม่ควรที่จะทำรายการได้

I คือ Isolation คือการ ที่การกระทำแต่ละอันไม่ขัดต่อกัน
เช่น
ID Name Balance
1  nueng 100
2  john  100
การทำการทำการโอนเงิน2คนพร้อมกัน 
ืnueng โอน 20 และ john โอน 20 พร้อมกัน
ส่งข้อมูลมาพร้อมกันเพื่อกันไม่ให้ database มีข้อมูลที่ผิดพลาดก็อาจจะใช่แบบ first in first out  ให้ทำรายการการโอนของืnuengเสร็จก่อนแล้วค่อยทำรายการการโอนของjohn

D คือ Durability คือการ มีอะไรสักอย่างสำรองข้อมูลไว้โดยที่ทำให้ระบบยังสามารถทำงานต่อได้โดยต้อง
