## Response Section
Json แตกต่างจาก Protocol Buffers โดยตัวของ Json จะเก็บข้อมูลเป็น ข้อความ แต่ตัว Protocol Buffers เก็บแบบ Binary

ข้อดีของ Json คือ สามารถเข้าใจ ได้เลยว่าข้ออะไร และ ไม่จำเป็นต้องกำหนด ว่าเป็น str หรือ int / float ตัวjsonจะกำหนดให้เลยตามข้อมูลที่ส่ง และ มีภาษาที่รับรองเยอะ

ข้อเสียของ Json คือ ใช้พื้นที่เยอะกว่าตัว Protocol Buffers เพราะเก็บเป็น Text format และต้องส่งชื่อ Field ไปด้วย และ เมือไม่กำหนด type ข้อมูลจะทำให้เกิด error ได้เมื่อส่งคนละtype แต่เป็นตัวแปลเดียวกัน เช่น  
"id": 1,(int) กับ  "id": "hello",(str)ส่งได้เพราะไม่ต้องกำหนด type

ข้อดี Protocal Buffers คือ สามารถกำหนด type ได้ และมีความเร็วกว่าเพราะไม่ต้องแปลงกลับไป
เป็น binary เพราะเป็นอยู่แล้ว และทำให้ขนาดของข้อมูลนั้นใช้น้อยกว่า Json
ข้อเสีย Protocal Buffers คือ คืออ่านยากเพราะข้อมูลที่ได้จะเป็น binary ต้องแปลงข้อมูลก่อนถึงจะรู้ได้ว่าข้อมูลแบบไหน
